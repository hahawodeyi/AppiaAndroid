### Task 7: i18n 双语言核对（脚本 + 抽查）

**Files:**
- Create: `.superpowers/tmp-m11/i18n-diff.py`（一次性脚本，不入仓库——目录已在 .gitignore 的 .superpowers/ 下）
- Modify: 修复不对称差异时触 `app/src/main/res/values*/strings.xml`
- Read: RN `src/i18n/en.json` / `zh.json`

**Interfaces:**
- Consumes: AA 两侧 strings.xml（各 1148 行）；RN locale 双 json
- Produces: 差异裁定清单（任务报告承载，T8 入协议）；若 zh/en 键不对称 → 必修（主链路）

- [ ] **Step 1: 写比对脚本并运行**

```python
#!/usr/bin/env python3
# .superpowers/tmp-m11/i18n-diff.py — M11 一次性 i18n 比对
import json, re, sys
from pathlib import Path

AA_EN = Path("app/src/main/res/values/strings.xml")
AA_ZH = Path("app/src/main/res/values-zh/strings.xml")
RN = Path("/Users/bitmain/Projects/rebuild-mobile/appiaMobile/src/i18n")

def keys_of(xml: Path) -> dict[str, str]:
    text = xml.read_text(encoding="utf-8")
    out = {}
    for m in re.finditer(r'<string name="([^"]+)"[^>]*>(.*?)</string>', text, re.S):
        out[m.group(1)] = m.group(2)
    return out

en, zh = keys_of(AA_EN), keys_of(AA_ZH)
rn_en = {k.lowercase() if hasattr(k, "lowercase") else k.lower(): v
         for k, v in json.loads((RN / "en.json").read_text(encoding="utf-8")).items()}
rn_zh = {k.lower(): v for k, v in json.loads((RN / "zh.json").read_text(encoding="utf-8")).items()}

print("== AA zh 有而 en 无 ==");  print("\n".join(sorted(set(zh) - set(en))) or "(无)")
print("== AA en 有而 zh 无 ==");  print("\n".join(sorted(set(en) - set(zh))) or "(无)")
print("== RN en 有而 AA 无（lowercase 归一）==")
missing = sorted(set(rn_en) - set(en))
print("\n".join(missing) or "(无)")
print(f"（共 {len(missing)} 键——逐条裁定：各域授权差异/未使用键/缺口）")
print("== AA 有而 RN en 无 ==");  print("\n".join(sorted(set(en) - set(rn_en))) or "(无)")

# 占位符一致性（AA 两侧）
ph = re.compile(r"%\d+\$[sd]")
for k in sorted(set(en) & set(zh)):
    if sorted(ph.findall(en[k])) != sorted(ph.findall(zh[k])):
        print(f"== 占位符不一致 == {k}: en={ph.findall(en[k])} zh={ph.findall(zh[k])}")
```

运行 `python3 .superpowers/tmp-m11/i18n-diff.py`，保存输出。
